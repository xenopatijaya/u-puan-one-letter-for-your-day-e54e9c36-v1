An entry for make.fun's "One Letter for Your Day" bounty. The program writes exactly one letter to `/output/entry.txt`: **H** — for "hangry", a day summed up in one sensation: lunch skipped, stomach growling, temper shortening with every unread message. One letter, no word, no gloss, no punctuation.

## Run it

```sh
python3 main.py
```

This writes the single letter `H` to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
